# Intranets por cliente

Estructura objetivo del repositorio:

- `clientes/tibox/tibox-hub/` — TIBOX HUB (actualmente el proyecto histórico sigue en la raíz mientras se completa la migración sin romper CI).
- `clientes/vgm/intranet/` — Intranet VGM en SharePoint Framework.

Cada cliente tendrá su propio proyecto SPFx, IDs de solución, permisos, fuentes de datos y paquete `.sppkg` independiente.
